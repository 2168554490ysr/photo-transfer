# 模块 3 — L1 用户需求

---

## REQ-01: 磁盘空间预检

**行为契约**: 下载开始前检查 PC 目标磁盘剩余空间是否大于待下载文件总大小。空间不足则拒绝下载并退出。

**验收条件**:
- 剩余空间 >= 待下载总大小 → 继续下载
- 剩余空间 < 待下载总大小 → 退出，输出"磁盘空间不足: 需要 X GB, 剩余 Y GB"
- 无法获取磁盘信息 → 记录警告，继续下载（不做阻塞）

---

## REQ-02: 批量下载

**行为契约**: 逐个下载待下载清单中的文件到 PC，按文件修改时间组织到 `YYYY-MM-DD/` 子目录。

**验收条件**:
- 文件 `mtime` 为 2026-07-12 → 保存到 `<target_root>/2026-07-12/`
- 父目录不存在 → 自动创建
- 目标文件已存在（同名同路径）→ 跳过（视为已完成）
- 目标文件已存在但大小不一致 → 删除不完整文件，重新下载

---

## REQ-03: 实时进度显示

**行为契约**: 下载过程中实时显示当前进度，包含序号、文件名、传输速度、预估剩余时间、已下载字节。

**验收条件**:
- 输出格式: `[N/Total] filename  XX.X MB/s  剩余约 X 分钟 (已下载 Y MB)`
- 每个文件下载完成后更新一行
- 大文件（≥8MB）下载中按实际落盘字节持续上报进度
- 传输速度基于最近 3 个文件的平均速度计算
- 所有文件下载完成后输出汇总: `完成: N 成功, M 失败`

---

## REQ-04: 断点续传

**行为契约**: 维护 `.sync_progress.json` 进度文件。中断后重新运行自动跳过已完成的文件，仅下载剩余部分。

**验收条件**:
- 每下载成功一个文件，立刻追加到进度文件的 `completed` 列表
- 中断后重新运行 → 读取进度文件 → 已完成的自动跳过
- 中断时正在传输的文件（不完整）→ 通过大小比对检测到 → 删除 → 重新下载
- 全量完成后进度文件标记 `status: "completed"`，保留记录

---

## REQ-05: 错误容忍

**行为契约**: 单个文件下载失败不中断整体流程。失败文件记录到错误列表，全部完成后汇总输出。

**验收条件**:
- 文件下载失败 1 次 → 自动重试 1 次
- 重试仍失败 → 记录到错误列表，继续下一个文件
- 全部完成后输出错误汇总（如有）: "N 个文件下载失败: [列表]"

---

## REQ-06: 同步日志

**行为契约**: 每次完整同步结束后写入 `.sync_log.json`，记录同步时间、文件总数、新增数、错误列表。

**验收条件**:
- 同步完成 → 生成/更新日志文件
- 日志包含: `{date, total_phone_files, new_downloaded, failed_list, duration_seconds}`
- 下次运行时可通过日志比较上次同步状态
