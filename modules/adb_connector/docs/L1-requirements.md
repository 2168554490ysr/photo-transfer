# 模块 1 — L1 用户需求

---

## REQ-01: USB 设备检测

**行为契约**: 运行时自动检测 USB 连接的 Android 设备。如检测到设备，返回设备序列号；如未检测到，输出明确错误信息并退出。

**验收条件**:
- 已授权 USB 调试的设备被 `adb devices` 列出 → 返回序列号
- 无设备连接 → 退出，输出"未检测到USB设备，请检查数据线连接和USB调试开关"
- 多设备连接 → 退出，输出"检测到多个设备，请只保留一台设备连接"

---

## REQ-02: 文件列表获取

**行为契约**: 给定手机上的目录路径，递归返回该目录下所有文件的基本信息（名称、大小、修改时间、完整路径）。仅返回文件，不返回目录。

**验收条件**:
- 传入 `/sdcard/DCIM/Camera` → 返回该目录下所有文件的 `{name, size, mtime, path}` 列表
- 传入不存在的路径 → 退出，输出"路径不存在: <path>"
- 传入无权限目录 → 退出，输出"无权限访问: <path>"

---

## REQ-03: 单文件下载

**行为契约**: 给定手机文件路径和PC目标路径，将文件从手机复制到PC。返回成功或失败。

**验收条件**:
- 文件存在且空间足够 → 下载成功，返回 true
- 文件不存在 → 返回 false，错误信息"文件不存在: <path>"
- PC路径父目录不存在 → 自动创建父目录后下载
- 下载超时（30s）→ 自动重试1次

---

## REQ-04: 设备信息获取

**行为契约**: 返回已连接设备的基本信息（型号、Android 版本、存储根目录列表）。用于首次配置时辅助用户填写扫描路径。

**验收条件**:
- 设备已连接 → 返回 `{model, android_version, storage_roots}`
- 设备未连接 → 行为同 REQ-01 无设备场景

---

## REQ-05: 命令超时与重试

**行为契约**: 所有 ADB 命令默认超时 30 秒。超时后自动重试 1 次，两次均失败则退出并报告错误。

**验收条件**:
- 命令在 30s 内完成 → 正常返回
- 命令超时 1 次 → 重试成功 → 正常返回
- 命令超时 2 次 → 退出，输出"ADB命令失败(重试2次): <command>"
